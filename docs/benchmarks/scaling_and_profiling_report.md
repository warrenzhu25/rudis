# Rudis High-Concurrency Multi-Core Scaling & CPU Profiling Report

## 1. Executive Summary & Benchmark Setup

- **Hardware Platform**: AMD EPYC 7B13 64-Core Processor (NUMA Node 0, 117 GiB RAM)
- **Server Configuration**: Dedicated pinned cores `0..(N-1)` driving independent `monoio` `io_uring` instances
- **Client Generator**: `memtier_benchmark` pinned to dedicated cores `32-63`
- **Workload Parameters**: 1KB payload, Pipeline Depth 100, 1,000,000 Key Keyspace

### Architectural Observations:
1. **Zero Mutex Contention**: Notice the absence of `pthread_mutex`, `futex`, or atomic CAS stalls in the top CPU symbols, validating the shared-nothing multi-reactor model.
2. **io_uring Proactor Saturation**: Kernel `io_uring_enter` and `monoio::driver` spend the majority of CPU cycles actively processing hardware network ring completions.
3. **Direct Memory Efficiency**: Zero-copy RESP parsing and inlined `RudisTable` hash lookups minimize CPU cache misses.
